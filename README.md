# 고유명사 지킴이

웹소설 원고를 맞춤법 검사기에 넣기 전에, 등장인물 이름·지명·세계관 용어를 임시 코드로 숨겼다가
검사가 끝나면 원래대로 되돌려 주는 도구입니다. 파일 하나(`index.html`)로 동작합니다.

**바로 사용하기: https://kurotoni.github.io/novel-spell-checker/**

## 1. 이 도구가 필요한 이유

맞춤법 검사기는 `루시아`, `에스페란자 왕국` 같은 창작 고유명사를 모릅니다. 그래서

- 멀쩡한 이름을 비슷한 단어로 "고쳐" 버리고
- 이름 뒤의 조사(은/는, 이/가, 을/를)를 엉뚱하게 바꿔 놓습니다.

그래서 이 도구는 **이름과 그 뒤에 붙은 조사를 한 덩어리로 숨깁니다.**

```
원본 : 루시아가 에스페란자 왕국으로 갔다.
치환 : [[PROTECTED_1]] [[PROTECTED_2]] 갔다.
복원 : 루시아가 에스페란자 왕국으로 갔다.
```

조사를 밖에 남겨 두면 검사기가 `[[PROTECTED_1]]가`의 `가`를 `이`로 바꾸는 사고가 납니다.
대신 **조사 맞춤법은 이 앱이 직접 검사**합니다. 받침 규칙을 알고 있으므로 검사기보다 정확합니다.

| 잘못 쓴 예 | 앱의 지적 |
| --- | --- |
| 루시아이 | 받침 없음 → `가` |
| 마나 심장를 | 받침 있음 → `을` |
| 아르실으로 | ㄹ 받침 → `로` |
| 루시아님이 | 호칭 `님`의 받침 기준으로 판정 (정상) |

## 2. 사용 순서

1. **왼쪽 사전에 고유명사 등록** - 입력 후 Enter, 또는 쉼표로 여러 개 한 번에. 브라우저에 자동 저장됩니다.
2. **1단계에 원고 붙여넣기** - 이름 뒤 조사가 틀렸으면 알려 줍니다. `고치기` 또는 `모두 교정`.
3. **`고유명사 숨기기 (치환) + 복사`** - 이름과 줄 표시가 들어간 글이 클립보드에 복사됩니다.
4. **2단계의 검사기 링크 열기** - 붙여넣고 맞춤법 검사를 받습니다.
5. **고쳐진 글을 3단계에 붙여넣고 `되돌리기`** - 이름과 줄 구조가 함께 원래대로 돌아옵니다.
6. **`최종 원고 복사하기`**

### 줄바꿈이 사라지는 문제

외부 맞춤법 검사기는 결과를 돌려줄 때 줄바꿈을 없애 원고를 줄글로 만들어 버리곤 합니다.
그래서 치환할 때 각 줄 앞에 줄 표시를 함께 넣습니다.

```
원본 :   루시아가 창가에 섰다.
치환 : [[L1]][[PROTECTED_1]] 창가에 섰다.
```

검사기가 줄을 다 뭉개 놓아도 3단계에서 이 표시를 기준으로 원래 줄 구조를 정확히 되살립니다.
빈 줄, 들여쓰기, 대사 줄까지 그대로 복구됩니다. 왼쪽 `치환 옵션`의 `줄바꿈 보호`로 켜고 끕니다.

줄 표시가 일부 사라지면 몇 번째 줄이 영향을 받았는지 알려 줍니다. 그 줄의 내용은 앞줄에 붙어
있으니 직접 나누면 됩니다. **내용이 사라지지는 않습니다.**

### 주의

- 치환표(번호 ↔ 원래 이름)는 이 브라우저에만 저장됩니다. **시크릿 창을 닫거나 브라우저 데이터를 지우면 사라집니다.**
  1단계와 3단계는 되도록 한 번에 마치세요. (새로고침이나 브라우저 재시작은 괜찮습니다.)
- 검사기가 치환 코드를 통째로 삭제하는 경우가 드물게 있습니다.
  복원 후 "사라진 것으로 보이는 고유명사" 안내가 뜨면 그 부분을 직접 확인하세요.
- 네이버 검사기는 한 번에 넣을 수 있는 글자 수에 제한이 있습니다. 길면 나눠서 검사하고,
  치환 코드가 글자 수를 많이 차지하면 왼쪽 `치환 코드 모양`을 `[[1]] (짧게)`로 바꾸세요.

## 3. GitHub Pages 배포 방법 (비개발자용)

1. GitHub에 로그인하고 오른쪽 위 `+` → **New repository**.
2. Repository name에 예를 들어 `novel-spell-checker` 를 넣고, **Public**을 선택한 뒤 **Create repository**.
3. 만들어진 화면에서 **uploading an existing file** 링크를 누릅니다.
4. `index.html` 파일을 끌어다 놓고 아래 **Commit changes** 버튼을 누릅니다.
5. 위쪽 **Settings** 탭 → 왼쪽 메뉴 **Pages**.
6. `Branch` 항목에서 **main** 과 **/ (root)** 를 선택하고 **Save**.
7. 1~2분 뒤 새로고침하면 주소가 나옵니다.
   `https://<내아이디>.github.io/novel-spell-checker/`

파일을 고쳤으면, 저장소 화면에서 `index.html`을 클릭 → 연필 아이콘 → 수정 → Commit 하면 몇 분 뒤 반영됩니다.

> 참고: `index.html`을 바탕화면에 두고 더블클릭해도 그대로 동작합니다. 다만 이때는
> 자동 복사가 막히는 브라우저가 있어 `복사` 버튼을 한 번 더 눌러야 할 수 있습니다.
> GitHub Pages(https)에 올리면 자동 복사까지 정상 동작합니다.

## 4. 코드 수정 가이드

`index.html` 하나에 화면과 기능이 모두 들어 있습니다. `<script>` 안은 `[1] ~ [13]` 번호로 구역이
나뉘어 있으니, 메모장이나 브라우저에서 `[2]` 처럼 검색해 찾으면 됩니다.

### 버튼 색이나 모양을 바꾸고 싶을 때 → 파일 맨 위 `<style type="text/tailwindcss">`

반복해서 쓰는 조각을 이름 있는 클래스로 묶어 두었습니다. HTML을 뒤질 필요 없이 여기만 고치면
같은 클래스를 쓰는 곳이 전부 함께 바뀝니다.

```css
.btn-indigo { @apply bg-indigo-600 text-white hover:bg-indigo-500; }
```

`indigo`를 `rose`로 바꾸면 주요 버튼이 전부 붉은 계열이 됩니다.
사용 가능한 색: slate, gray, red, rose, amber, emerald, teal, sky, blue, indigo, violet 등이며
숫자는 50(밝음)~950(어두움)입니다.

두 가지만 지키세요.

- 이 블록에서는 **Tailwind 기본 클래스만** `@apply` 할 수 있습니다. 여기서 만든 `.card` 같은
  이름을 다시 `@apply` 하면 스타일이 통째로 깨집니다.
- HTML에서 `class="btn py-4"` 처럼 **유틸리티로 덮어쓰지 마세요.** 적용 순서에 따라 결과가
  달라집니다. 필요한 모양은 이 블록에 새 클래스로 만들어 쓰면 됩니다.

### 조사를 더 넣고 싶을 때 → 구역 `[2]`

```js
const PARTICLE_PAIRS = [
  ['은','는'], ['이','가'], ...   // [받침 있을 때, 받침 없을 때]
];
const PARTICLE_PAIRS_RO = [
  ['으로','로'], ...              // ㄹ 받침 뒤에서는 '로'를 쓰는 무리
];
const PARTICLES_FIXED = [
  '의','에','에게','까지', ...    // 모양이 바뀌지 않는 조사
];
const SUFFIXES = ['님','씨','양','군','짱','쨩'];  // 이름 뒤 호칭
```

`PARTICLES_FIXED`에 `'라며'`를 추가하고 싶다면 목록 안에 `'라며',` 를 넣으면 됩니다.
받침에 따라 모양이 바뀌는 조사라면 `PARTICLE_PAIRS`에 `['이라며','라며']` 형태로 넣으세요.
검사 규칙은 이 표에서 자동으로 만들어지므로 다른 곳은 손댈 필요가 없습니다.

### 치환 코드 모양을 바꾸고 싶을 때 → 구역 `[6]`

```js
function makePlaceholder(id, style) {
  return style === 'short' ? '[[' + id + ']]' : '[[PROTECTED_' + id + ']]';
}
```

바로 아래에 되돌리기 규칙(`RE_LINEMARK`, `RE_PROTECTED`)이 있습니다. 모양을 완전히 새로 만들면
그 규칙도 함께 고쳐야 합니다. 되도록 대괄호 형태는 유지하세요.

### 원고지 계산 기준을 바꾸고 싶을 때 → 구역 `[7]`

```js
'자 · 원고지 ' + (all / 200).toFixed(1) + '매';   // 200자 원고지 기준
```

### 치환 옵션을 하나 늘리고 싶을 때 → 구역 `[10]`

HTML에 입력칸(체크박스나 선택상자)을 만들고 아래 표에 한 줄만 추가하면 저장과 불러오기가
자동으로 처리됩니다.

```js
const OPTION_FIELDS = {
  lines: 'optLines',        // 왼쪽이 저장될 이름, 오른쪽이 HTML의 id
  boundary: 'optBoundary',
  ...
};
```

### 맞춤법 검사기 링크를 추가하고 싶을 때

HTML에서 `네이버 맞춤법 검사기 열기` 를 검색하면 링크 버튼이 나옵니다.
그 `<a ...>` 줄을 복사해 `href="..."` 와 글자만 바꾸면 버튼이 하나 더 생깁니다.

### 화면 요소를 추가할 때

HTML 태그에 `id`를 붙이기만 하면 JS에서 `el.붙인아이디` 로 바로 쓸 수 있습니다.
따로 등록하는 목록이 없으므로 빠뜨릴 일이 없습니다.

## 5. 자주 묻는 질문

**Q. 내 원고가 어디로 전송되나요?**
아니요. 모든 처리는 브라우저 안에서만 이뤄지고 서버로 보내지 않습니다. (2단계에서 검사기 사이트에
직접 붙여넣는 것은 별개입니다.)

**Q. '검'을 등록했더니 '검색'까지 바뀔까 봐 걱정됩니다.**
`단어 경계 확인` 옵션이 켜져 있으면 뒤에 조사가 아닌 글자가 붙은 경우 건드리지 않습니다.
`검색`은 그대로 두고 `검을`, `검은` 만 치환합니다.

**Q. 두 이름이 겹칩니다. (루시아 / 루시아나)**
항상 긴 이름을 먼저 찾습니다. `루시아나는` 은 `루시아나 + 는` 으로 처리됩니다.

**Q. 이 앱이 맞춤법도 고쳐 주나요?**
아니요. 고유명사 뒤 **조사만** 검사합니다. 받침 규칙을 알아야 하는 부분이라 외부 검사기가
원리적으로 판단할 수 없기 때문입니다. 일반 맞춤법은 2단계의 외부 검사기에 맡깁니다.

**Q. 인터넷이 끊긴 상태에서도 되나요?**
디자인(Tailwind CSS)을 인터넷에서 받아오므로, 오프라인에서는 화면이 흐트러집니다.
기능 자체는 동작합니다.
